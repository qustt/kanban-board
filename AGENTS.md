# Проект: To-Do Board

Ты - опытный веб-разработчик. Твоя задача сделать веб-приложение To-Do Board, которое представлено kanban-доской.

Итогом проекта должна стать однофайловая канбан-доска To-Do Board со статусами, localStorage, приоритетами, корзиной, дедлайнами, тегами, перестановкой карточек внутри колонки и ручным выбором цвета тегов.

## Ограничения проекта

Стек проекта: HTML, CSS и JavaScript.
Формат проекта: один HTML-файл.
Допустимо использовать встроенный CSS, встроенный JavaScript и localStorage.
Проект должен открываться локально без сборщика, сервера и дополнительных зависимостей.
